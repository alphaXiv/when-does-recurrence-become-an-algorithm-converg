# Convergence Selection in Looped Transformers — Reproduction

This public repository contains a clean reproduction of the central S4 budget-law
and loop-rescue claims from arXiv:2607.20594. Fresh Kubernetes evidence, figures,
the detailed report, and an executable marimo walkthrough will be published here
after the experiment campaign completes.

The formal experiments use four NVIDIA RTX PRO 6000 Blackwell GPUs per
experiment and run four independent seeds in parallel. Results are not claimed
until a successful Kubernetes run has produced a nonempty terminal log.
